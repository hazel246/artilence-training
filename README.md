# Artilence Training

Training repo for my industrial FYP work with Artilence, covering both the AI/Agents track and the Database track.

## AI Track (LLM, RAG & Agents)

Phased training covering LLM foundations through multi-agent production systems, applied where possible to Artilence's SooqSense product context.

- [ ] **Phase 1: LLM Foundations** - tokenization, reasoning models, frontier/open/local models, structured outputs, tool calling, prompt caching
- [ ] **Phase 2: LangChain Core & Context Engineering** - LCEL, chains, context window budgeting, summarisation
- [ ] **Phase 3: Agents, Tools, MCP & LangGraph** - ReAct, MCP servers, LangGraph, checkpointing, human-in-the-loop, agent memory
- [ ] **Phase 4: Advanced RAG & Vector Databases** - chunking strategies, contextual retrieval, hybrid search, rerankers, agentic RAG, GraphRAG, RAGAS
- [ ] **Phase 5: Multi-Agent Systems & Production (AgentOps)** - supervisor patterns, A2A, guardrails, tracing, model routing, FastAPI deployment
- [ ] **Phase 6: Multimodal, Realtime & Model Customization** - voice agents, browser agents, LoRA/QLoRA, DPO
- [ ] **Phase 7: Mastery & Real-World Applications** - capstone project
